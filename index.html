Things we'd add in v2.

A few moves I'd make once the core is real:

📸
Before / after photos
Per-clean photo upload. Doubles as marketing content and insurance protection.
💬
Private feedback loop
"How did Maria do today?" — only Doris sees it. Catches issues early, builds preference data.
🎁
Tip flow + referral codes
Tip after the clean. Refer a neighbor → both get $25 credit. Compounds over time.
📦
Supply tracker
Mark "low on Mrs. Meyers" from the field. Doris orders before things run out.
📨
SMS thread per client
Every text routes through one place. Doris never loses context across clients.
🌿
Seasonal promos
Auto-emailed: spring deep clean, holiday prep, post-renovation. Re-engagement for monthly clients.
